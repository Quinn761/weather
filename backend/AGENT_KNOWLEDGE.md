# Agent 项目问答的维护

`src/main/resources/ai/project-knowledge.md` 是随版本发布的项目事实说明，包含模块、权限、表、工具能力、部署方式和限制，并附源码路径。修改功能、接口、权限、表、模型链路或部署方式时，应在同一变更中更新对应章节。它是人工核对后的版本说明，不是运行时扫描所有源码。

`ProjectKnowledge` 将说明装入回答上下文，并按章节加入 RAG。数据库中有文章时也不会覆盖掉项目说明；只有有 `kb:read` 权限的用户才能检索启用的数据库文章。旧数据库文章与当前实现冲突时，回答优先参考随版本发布的说明。不要把凭据、生产日志、联系方式或实时统计写入项目说明。

`ContextualPlanner` 使用当前问题和最近 20 条会话消息选择工具，保留模型补全的参数，最多 6 次只读查询；模型不可用时使用 `HeuristicPlanner`。`SystemDataTool` 按 scope 查询用户、角色、菜单、知识文章元数据和当前后端安全配置/连通性。用户查询每页 20 条且不返回密码、电话和邮箱；其他查询遵守原有页面读权限。未接入的数据和服务必须明确未知，不能声称自动运维或已验证远端部署。

验证：用 JDK 21 执行 `mvnw test`；前端执行 `npm run build`。生产流水线构建前后端，并把 Python 应用源码发布为版本化 ConfigMap，挂载到已有 Python/SAM 容器的 `/app/app`，恢复副本后等待就绪。依赖与模型镜像仍需独立更新。验证问题可使用“当前系统有哪些功能”“AI 圈地怎么实现”“现在有哪些角色和菜单”“我有什么权限”“Redis 当前是否可用”，并检查回答的执行记录。
